## 📁 تێڕوانینی گشتی

ئەم ڕێپەڕە پڕە لە جێبەجێکردنی تەواوی HAL بۆ سیمرغ ئۆئێس، بەپێی بنەماکانی دیزاین کە لە بەڵگەنامەی تەلارسازییەکەدا هاتووە. HAL **تاکە چینە** کە ڕاستەوخۆ لەگەڵ ئامێر (ڕیجستەرەکان، MMIO، فەرمانە تایبەتەکانی CPU) کارلێک دەکات و ڕووپەڕێکی یەکگرتوو بۆ مایکرۆکرنێل (چینی ٢) و چینە بەرزترەکان دابین دەکات.

### بنەما سەرەکییەکانی دیزاین
- ✅ **بێ پشتبەستن بە سیستەم** - هەموو کریتەکان `#![no_std]` بەکار دەهێنن
- ✅ **سەربەخۆ لە تەلارسازی** - هیچ `#[cfg(target_arch)]` لە سەرووی چینی ١ نییە
- ✅ **دۆزینەوەی ئامێر هەمیشە** - تەواوی ئامێر بەبێ گوێدانە پڕۆفایلەکە دەدۆزرێتەوە
- ✅ **دەستگەیشتنی ڕاستەوخۆی توانایی-دروازەکراو** - `hal-direct` پێویستی بە تۆکەنی دروست هەیە
- ✅ **مانیفیست بە قەبارەی جێگیر** - `#[repr(C)]` بۆ گواستنەوەی کاتی بوت

## 📄 ڕوونکردنەوەی فایلەکان

### فایلە سەرەکییەکانی بۆشایی کار

| فایل | ئامانج |
|------|---------|
| `Cargo.toml` | بۆشایی کاری سەرەکی لەگەڵ ئەندامان: `hal-*`، `kernel-stub` |
| `rust-toolchain.toml` | دیاریکردنی nightly Rust لەگەڵ پێکهاتە پێویستەکان |
| `.cargo/config.toml` | ڕێکخستنەکانی Cargo (ئامانج، لینکەر، جێبەجێکەر بۆ QEMU) |

### تایبەتمەندییەکانی ئامانج (`targets/`)

| فایل | ئامانج |
|------|---------|
| `x86_64-hal.json` | ئامانجی تایبەت بۆ `x86_64-unknown-none` لەگەڵ `#![no_std]` |
| `aarch64-hal.json` | ئامانجی تایبەت بۆ `aarch64-unknown-none` |
| `riscv64gc-hal.json` | ئامانجی تایبەت بۆ `riscv64gc-unknown-none-elf` |

ئەم فایلانە دیاری دەکەن:
- تایبەتمەندییەکانی CPU (وەک `mmx`، `sse`، `avx` بۆ x86_64)
- ڕێکخستنی داتا و ڕیزبەندی
- ستراتیژی هەڵە (`abort`)
- مۆدێلی کۆد (`kernel`)

---

### کریتەکانی HAL

#### ١. `hal-manifest` - پێکهاتەکانی داتای مانیفیستی ئامێر
**ئامانج:** پێناسەکردنی داتای گواستنەوەی ئامێری کاتی بوت.

**فایلە سەرەکییەکان:**
- `raw.rs` - لەخۆگرێتی `HardwareManifestRaw` لەگەڵ ڕێکخستنی `#[repr(C)]`
  - ئارایەکانی قەبارە جێگیر (٦٤ ناوچەی بیرگە، ٣٢ ئامێری ژمێریاری، ١٦ دۆمەینی وزە)
  - بێ تەرخانکردنی heap، بێ `serde`
  - تەنها لە کاتی گواستنەوەی بوت بەکار دەهێنرێت (HAL → مایکرۆکرنێل)

**پشتبەستنەکان:** تەنها `core` (بێ `alloc`)

---

#### ٢. `hal-core` - تڕەیتە سەرەکییەکانی HAL
**ئامانج:** پێناسەکردنی ڕووپەڕی یەکگرتووی ڕەتکردنی ئامێر.

**فایلە سەرەکییەکان:**

| فایل | تڕەیت | بەرپرسیارێتییەکان |
|------|-------|------------------|
| `cpu.rs` | `CpuAbstraction` | ژمارەی ناوک، ناسنامەی ناوکی ئێستا، ئاڵا تایبەتمەندییەکان، گۆڕینی چوارچێوە، ئاستەکانی ماف |
| `memory.rs` | `MemoryBootstrap` | نەخشەی بیرگەی فیزیایی، نەخشەکردنی ناسنامەیی، دۆزینەوەی IOMMU |
| `timer.rs` | `TimerAbstraction` | کاتی ئێستا (نانۆچرکە)، ڕەوشەکانی یەک-تەپە/بێ-تیک |
| `interrupt.rs` | `InterruptController` | `register_irq`، `mask_irq`، `unmask_irq`، `send_ipi` |
| `compute.rs` | `ComputeDeviceDiscovery` | ژماردنی ئامێرەکانی GPU/NPU/TPU/FPGA |
| `power.rs` | `PowerManagement` | پرسيار/ڕێکخستنی DVFS، خوێندنەوەی پلەی گەرمی |
| `boot.rs` | `BootInfo` | پێکهاتەی ستانداردی گواستنەوەی بوت |
| `error.rs` | `HalError` | جۆری هەڵەی یەکگرتوو |

**پشتبەستنەکان:** تەنها `core`

---

#### ٣. `hal-direct` - دەستگەیشتنی ڕاستەوخۆی توانایی-دروازەکراو
**ئامانج:** دابینکردنی دەستگەیشتنی خاوی ئامێر بۆ بەکارهێنەرانی پێشکەوتوو.

**تایبەتمەندییە سەرەکییەکان:**
- هەموو فەرمانەکان پێویستیان بە `CapabilityToken` ی دروست هەیە
- تۆکەنەکان لەلایەن برۆکەری ئاسایش (چینی ٤) دەردەچن
- HAL تەنها دروستی تۆکەن پشتڕاست دەکاتەوە (واژۆ/بوار)
- کردارەکانی ئامادە:
  - `map_mmio_region` - نەخشەکردنی ڕاستەوخۆی MMIO
  - `read_performance_counter` - خوێندنەوەی ژمێرەکانی ئاستی کارایی
  - `pin_thread_to_core` - پەیوەستکردنی تەردی بە ناوک
  - `set_numa_policy` - سیاسەتی بیرگەی NUMA

**پشتبەستنەکان:** `hal-core`، `hal-manifest`

---

#### ٤. کریتە تایبەتەکانی تەلارسازی (`hal-x86_64`، `hal-arm64`، `hal-riscv64`)

**ئامانج:** جێبەجێکردنی هەموو تڕەیتەکانی HAL بۆ هەر تەلارسازییەک.

**فایلە هاوبەشەکان:**

| فایل | ئامانج |
|------|---------|
| `lib.rs` | خاڵی چوونەژوورەوە، هەناردەکانی جێبەجێکردنی تڕەیتەکان |
| `boot.S` | ڕاهێنانی سەرەتایی ئەسمبلی (پێش دەستپێکردنی Rust) |
| `linker.ld` | سکریپتی لینکەر دیاریکەری ڕێکخستنی بیرگە (ناونیشانی بنچینەی کرنێل، پاشکۆ و هتد) |
| `cpu.rs` | ڕەتکردنی CPU ی تایبەت بۆ تەلارسازی |
| `memory.rs` | ڕاهێنانی بیرگە (e820/UEFI بۆ x86، ACPI/DT بۆ ARM، SBI/DT بۆ RISC-V) |
| `timer.rs` | جێبەجێکردنی تایمەر (TSC/HPET، تایمەری گشتی، mtime) |
| `interrupt.rs` | کۆنترۆڵکەری تەپۆڵ (APIC، GIC، PLIC) |

**وردەکارییە سەرەکییەکانی جێبەجێکردن:**

| تەلارسازی | تایمەر | کۆنترۆڵکەری تەپۆڵ | سەرچاوەی بوت |
|--------------|-------|---------------------|-------------|
| **x86_64** | TSC/HPET | APIC/x2APIC | نەخشەی بیرگەی UEFI / e820 |
| **ARM64** | تایمەری گشتی | GIC v3/v4 | ACPI (پێشینە) یان Device Tree |
| **RISC-V** | mtime/mtimecmp | PLIC + CLIC | SBI + Device Tree (پێویست) |

---

#### ٥. `kernel-stub` - ستابی تاقیکردنەوەی MVP
**ئامانج:** ستابی کاتی مایکرۆکرنێل بۆ پشتڕاستکردنەوەی دروستی HAL.

**بەرپرسیارێتییەکان:**
- وەرگرتنی `HardwareManifestRaw` لە HAL
- چاپکردنی "سڵاو لە کرنێل" لەسەر پۆرتی زنجیرەیی
- پشتڕاستکردنەوەی کارکردنی دروستی دۆزینەوەی ئامێر
- جێبەجێکردنی کەمترین - بە مایکرۆکرنێلی ڕاستەقینە (چینی ٢) دەگۆڕدرێت

**دۆخی ئێستا:** ✅ پێکهاتە دروست کرا، چاوەڕوانی جێبەجێکردن
